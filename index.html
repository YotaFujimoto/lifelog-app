ライフログ連携（個人用）

このアプリは、開発者本人が自分の Fitbit（Google Health）の睡眠と運動の記録を、自分の Notion に書き写すためだけに使う個人用のツールです。ほかの人には提供していません。

プライバシーポリシー

  • 読み取るデータ：Google Health API の睡眠データと運動データだけです（読み取り専用の許可）。Google Health に書き込むことはありません。
  • 使い道：開発者本人の Notion に書き込むためだけに使います。第三者への提供、広告への利用、販売はしません。
  • 保存：認証情報は非公開の GitHub リポジトリのシークレットにだけ保存します。読み取ったデータは、開発者本人の Notion 以外には保存しません。
  • 取り消し：Google アカウントの「サードパーティ製のアプリとサービスとの接続」から、いつでもアクセスを取り消せます。

This is a personal tool used only by its developer to copy their own Fitbit sleep and exercise records from Google Health to their own Notion workspace. It reads data with read-only scopes, does not share data with third parties, and does not use it for advertising. The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements, and to the Google Health API Developer and User Data Policy.
